# Credits

The method comes from [`shuorenhua`](https://github.com/MrGeDiao/shuorenhua) (说人话), a Chinese-first AI-tone cleanup skill: sort the defect by layer, look at the word before touching the sentence, and keep a list of concrete pairs instead of adjectives.

The English side draws on the same idea as the public `anti-slop` writing rules: name the concrete behavior instead of the adjective.

Both are references for method only. This skill has no runtime dependency on either project, and its examples come from this organisation's own repositories.
