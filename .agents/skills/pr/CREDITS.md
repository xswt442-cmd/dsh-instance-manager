# Credits

This PR Skill was originally adapted from [Dex Horthy](https://github.com/dexhorthy)'s [`show-me` approach](https://github.com/humanlayer/humanlayer) to making changes easier to review. Its optional use of diagrams and focused diff excerpts draws on that work.

This version favors explanatory prose, a completed-task checklist, real verification results, and the repository's existing PR template. It does not require visuals or the original Summary / Evidence / Merge Danger layout, and has no runtime dependency on `show-me`.
